# NovaWeb — site vitrine

Site statique responsive pour présenter l'activité NovaWeb.

## Contenu
- `index.html` : structure et textes du site
- `styles.css` : design responsive, animations, cartes portfolio et maquettes CSS
- `script.js` : navigation mobile, filtres portfolio, modales, animation d'apparition, barre de progression et formulaire mailto

## Avant la mise en ligne
1. Ouvrez `script.js` et remplacez `VOTRE-EMAIL@EXEMPLE.FR` par votre vraie adresse e-mail.
2. Vérifiez les textes, les services et les coordonnées.
3. Les 4 éléments du portfolio sont des concepts fictifs de démonstration. Gardez la mention correspondante ou remplacez-les par vos vraies réalisations avec autorisation.
4. Le formulaire utilise `mailto:` : il ouvre l'application e-mail du visiteur et n'envoie pas directement les messages. Pour recevoir les formulaires en ligne sans application e-mail, il faudra connecter un service de formulaire ou un backend.
5. Les polices Google nécessitent une connexion internet. Des polices système prendront le relais si elles ne chargent pas.

## Tester localement
Double-cliquez sur `index.html` pour l'ouvrir dans un navigateur. Pour un test plus fiable, utilisez un serveur local statique.

## Personnalisation
Recherchez `NovaWeb`, l'adresse e-mail de démonstration et les textes à adapter dans les trois fichiers.
